= Installation

Ajouter dans votre `shard.yml` :

[source,yaml]
----
dependencies:
  asciicrystal-mathematical:
    github: aloli-crystal/asciicrystal-mathematical
    version: "~> 0.3.5.3"
----

Puis executer `shards install`.

Pour le rendu cote serveur (optionnel) :

[source,bash]
----
npm install -g katex
----

= Installation

Ajouter dans votre `shard.yml` :

[source,yaml]
----
dependencies:
  crystal-asciidoctor-mathematical:
    github: aloli-crystal/crystal-asciidoctor-mathematical
    version: "~> 0.1"
----

Puis executer `shards install`.

Pour le rendu cote serveur (optionnel) :

[source,bash]
----
npm install -g katex
----

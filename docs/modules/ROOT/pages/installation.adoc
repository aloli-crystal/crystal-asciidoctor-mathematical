= Installation

Add to your `shard.yml`:

[source,yaml]
----
dependencies:
  asciicrystal-mathematical:
    github: aloli-crystal/asciicrystal-mathematical
    version: "~> 0.3.5.3"
----

Then run `shards install`.

For server-side rendering (optional):

[source,bash]
----
npm install -g katex
----
